# 비즈니스 핵심 폼 묶음

견적서 → 발주서 → 계약서 → 청구서 순서로 활용할 수 있는 4종 템플릿입니다.

## 파일 목록

| 파일 | 설명 |
|------|------|
| `01_quotation.html` | 견적서 (Quotation) |
| `02_invoice.html` | 청구서 (Invoice) |
| `03_purchase_order.html` | 발주서 (Purchase Order) |
| `04_contract.html` | 용역계약서 (Service Agreement) |

## 사용 방법

1. 브라우저에서 각 HTML 파일을 엽니다.
2. 입력란(input/textarea)을 클릭해 내용을 수정합니다.
3. 브라우저 인쇄(Ctrl+P)로 PDF 저장 또는 인쇄합니다.
4. 인쇄 시 입력란 테두리가 깔끔하게 처리됩니다.

## 특징

- A4 인쇄 최적화
- 바로 편집 가능한 입력 필드
- 한국어 비즈니스 문서 관례 반영
- 품목 테이블, 금액, 계좌 정보, 서명란 포함
- 외부 라이브러리 없이 순수 HTML/CSS

## 커스터마이징 포인트

- 회사 로고 영역 추가 가능
- 품목 행 수 늘리기
- 자동 계산 기능은 JavaScript로 확장 가능
- 계약서 조항은 업종에 맞게 수정
