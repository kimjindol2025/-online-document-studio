# 무료 온라인 문서 작성 플랫폼 — 개발 시제품 v0.1

PRD v0.7 기반으로 공통 입력·검증·문서 미리보기·로컬 저장·인쇄를 동작하는 **브라우저 시제품**으로 구현한다. 기존 견적서 앱은 변경하지 않는다.

## 현재 동작하는 범위
- **공개 문서 3종:** 이력서(기본형), 시말서, 계약금·중도금·잔금 영수증
- **비공개 확장성 검증 1종:** 회의록 — JSON 정의만으로 엔진에서 검증·출력이 되는지 확인
- 문서 선택/검색, 질문형 입력, 필수항목·날짜·금액 검증, 반복 학력·경력 입력, A4 미리보기
- 브라우저의 **인쇄 기능을 이용한 PDF 저장**, 빈 양식 출력, 로컬 자동 저장/초안 복구/삭제
- JSON 백업 내보내기·가져오기(작성 내용이 파일에 포함되므로 보관 주의)
- 정의 JSON에서 공개 카탈로그와 문서별 독립 정적 검색 안내 HTML 생성

## 개발·검증 명령(191코딩 격리 작업공간)
```bash
node projects/online-document-studio/build-catalog.mjs
node --test projects/online-document-studio/tests/engine.test.mjs
```
191의 `coding_task_preview`로 `projects/online-document-studio/prototype/index.html`을 미리보기로 연다. 이 URL은 개발 시제품 전용이며 운영 도메인이 아니다.

## 문서 추가 방식
`definitions/`에 schemaVersion=1 문서 JSON 하나를 추가한다. `status: "public"`이면 빌드가 자동으로 카탈로그 및 문서별 HTML을 생성하고, `status: "internal"`이면 빌드 시 출판에서 제외한다. 새 문서 출시는 스키마/기능/출력/법적 위험 검수를 통과한 뒤에만 승인한다.

## 정확한 기술 상태
- **FreeLang 핵심 검증 프로브 PASS:** `core/document-rules.fl`을 FreeLang v11/FX 격리 실행기로 실행해 기본 필수값·양수금액·지급/수령자 10개 출력 확인.
- **브라우저 시제품은 임시 JS 어댑터:** 191 고정 MCP가 FreeLang Front 빌드/SSR/Island를 노출하지 않는다. HTML/CSS/JS는 배포 대상 정식 FreeLang Front 구현이 아닌, 빠르게 UX/입출력 계약을 검증하기 위한 임시 호환 계층. FreeLang Front 규칙·컴파일러 검증 후 정식 앱으로 이식해야 한다.
- PDF는 직접 바이너리 파일 생성이 아니라 브라우저 인쇄→PDF 저장 경로이며, **DOCX/XLSX/HWP/HWPX·팩스·클라우드·민원 접수는 구현되지 않았다**.
- 내부 미리보기 URL은 외부 인터넷에 공개되지 않는다. 정식 배포/연결/호스트 설정 변경 없음.

## 보안·법적 경계
작성 데이터는 브라우저의 localStorage에 평문으로 저장된다. 외부 서버 업로드 코드를 추가하지 않았으며, 방문 때 내려받는 정적 리소스는 예외다. **실제 브라우저 네트워크 감사 미실행**이므로 '서버 미전송 100% 검증 완료' 주장은 금지한다.
공용 PC, 브라우저 저장소 삭제, 악성 확장·사이트 스크립트 침해 등 위험이 있다. 법적 효력/공식 발급/실제 입금 증명·내용 작성 책임은 별개이며 본 시제품은 법률 상담 서비스가 아니다.
