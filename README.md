# 무료 온라인 문서 작성 플랫폼 — 개발 시제품

191 서버의 격리 테스트 작성기다. 기존 운영 서비스와 다른 프로젝트를 수정하거나 배포하지 않는다.

## 현재 기능

- 공개 양식20종: 이력서·시말서·영수증, 견적서·청구서·발주서·용역계약서·거래명세서, 자기소개서·재직증명서·근로계약서·사직서, 회의록·각서·품의서, 내용증명·비밀유지계약서·위임장·차용증·주택임대차계약서.
- 분류/검색, 입력 검증, 실시간 A4 미리보기, 반복 항목, 문서별 로컬 초안, JSON 백업·불러오기·초기화.
- 이력서 사진·크롭·3개 템플릿·미리보기 폼 변경·선택형 생년월일.
- 빈 양식·작성본 DOCX/HWPX/XLSX 다운로드. PDF는 브라우저 인쇄→PDF 저장 경로.
- 품목 금액·세액·합계 계산, 날짜 순서 검증, 원·년·% 구분.
- 비공개 확장성 검증1종(meeting-notes)은 메뉴에서 제외한다.

## 실행·검증

```bash
node build-catalog.mjs
node --test tests/*.test.mjs
python3 -m http.server 42800 --bind 127.0.0.1 --directory prototype
```

같은 서버에서 `http://127.0.0.1:42800/index.html`을 연다. 현재 테스트 서버가 이미 실행 중이면 추가로 시작할 필요가 없다. prototype만 제공하며 외부로 공개하지 않는다. 문서별 진입점은 index.html?doc=각ID다.

## 구현과 범위

definitions의 공개 JSON은 빌드 시 카탈로그/정적 안내 페이지로 생성된다. 지원 필드와 기존 렌더러 계약 안에서 정의를 추가한다. 새 계산이나 특수 레이아웃은 별도 구현·검증이 필요하다. 핵심 산술은 FreeLang으로 작성하고 검증된 스칼라 문법만 허용하는 빌드 브리지로 브라우저 모듈을 생성한다. DOM·저장·Office 형식은 JavaScript 어댑터다. 전체 FreeLang Front 컴파일러/다른 계열은 미검증이다.

편집용 다운로드는 표 형식이며 동일한 미리보기 배치는 PDF를 사용한다. 구형 HWP는 제공하지 않는다. 실제 Word·한글·Excel 프로그램의 편집/재저장 호환성, 다른 브라우저와 물리 인쇄는 미검증이다.

## 데이터와 운영

입력은 현재 브라우저의 localStorage에 평문으로 저장된다. 별도 서버 업로드 기능을 추가하지 않았다. 실제 사실·거래·발급권한·서명을 확인해야 하며, 법률/세무 자문이나 공식 접수·발급 기능을 제공하지 않는다. 원본 HTML은 sources에 보존하고 정적 서버에 노출하지 않는다. 운영 서비스 반영과 재시작은 별도 승인 대상이며, 저장소 커밋·푸시와 별개다.
